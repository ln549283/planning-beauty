# Planning beauté

Un planning personnel pour ajouter et supprimer des rendez-vous. Les données sont conservées dans le navigateur utilisé.

Depuis la racine du dépôt, démarrer le serveur avec Python 3 :

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Ouvrir l'application sur le port 8000. Aucune dépendance à installer.
